# E01 共同认知重现：探针实验

> **材料快照：** 本目录记录 2026-11-15 的实验，材料与答卷是当时快照，不是现行说明；项目名与个别表述已按公开口径脱敏，研究结论以当前文档为准。

## 目的

检验"共同认知"能否跨会话被恢复：给全新会话不同形式的材料，用同一组探针题检查它恢复了多少原有理解，尤其是否退回到思维链中已被排除的理解。

## 材料来源

Converge 的思维链文档：`idea.md`～`idea6.md`、`共同认知与重现.md`、`README.md`。探针题取自其中"最初这样想 → 后来修正"的位置。

## 对照组

所有组均为全新会话、同一模型、同一题面（`questions.md`），只有材料不同。

| 组 | 材料 | 状态 |
|---|---|---|
| B0 | 无材料（基线） | 完成 |
| B1a | 只给各文档的结论段落（总结 / 阶段性结论 / 核心推论），不含 README，约 3,200 字 | 完成 |
| B1b | 只给 README（跨文档的项目说明），约 2,400 字 | 完成 |
| B2 | 思维链原文 | 完成 |
| B3 | 结构化认知记录（AI 从原文抽取、人确认） | 未做：B2 已接近上限，在这组题上拉不开差距 |

每组跑 3 次。

## 判分规则

- 每题 0 / 1 / 2 分，另记"是否退回已排除的理解"（核心指标）。
- 盲评：各组答案打乱、去掉组别后由人打分。
- 每题标注"常识可达度"（高 / 中 / 低）。**基线答对只记为"常识可达"，不记为"思维链无增强或失效"**；常识可达题保留，不淘汰。
- 除结论外另看三项：
  - 依据是否项目特有（引用思维链中的理由与边界，而非通用道理）
  - 3 次之间结论是否稳定
  - 是否过度泛化（材料让回答变差，P7、P12 专测）
- 思维链的增强效果主要看低可达题，以及上述三项在各组间的差别。
- "坦承未知"与推断内容分开记：先声明不知道、随后给出推断的，推断内容仍按期望要点和失分信号判分；声明本身单独记一项。

## 执行方式

- 答题者为 DSH 子代理（`subagent`，不带本对话历史），路由固定为 `deepseek-official/deepseek-flash`，reasoning_effort=high。选它的理由：属于前沿模型，且有"容易快速提前下结论"的特点，材料能否抑制过早定论在它身上可能更明显。模型本身是变量，后续可换其他模型复测。
- 答题者只看到 `questions.md` 的题面和该组材料，禁止读取工作区任何文件；判分要点在 `probes.md`，不提供给答题者。
- 已知干扰：答题子代理仍会加载其运行环境的全局协作约定（含沟通偏好），各组相同。
- 每个会话一次答完全部题目，题间可能相互影响，各组相同。
- delegation: yes — 每次答题必须是独立的全新会话，主控本身已读过材料，不能自答。

## 文件

- `probes.md`：探针题与判分要点（答案键）
- `questions.md`：答题者看到的题面
- `runs/<组>-v<题目版本>-r<n>.md`：各次原始回答（v1 = 16 题、v2 = 20 题，均作存档；正式比较用 v3 = 22 题）
- `materials/`：各组所给材料的快照
- `scores.md`：判分表（待建）
